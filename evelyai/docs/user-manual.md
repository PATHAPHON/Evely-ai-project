# คู่มือการใช้งานระบบ EvelyAI 📘

ยินดีต้อนรับสู่คู่มือการใช้งานระบบ **EvelyAI** — แอปพลิเคชันผู้ช่วยฝึกฝนภาษาอังกฤษอัจฉริยะสำหรับคนไทย

---

## ⚡ 5-Minute Evaluator Tour (แนวทางการตรวจงานสำหรับกรรมการใน 5 นาที)

สำหรับอาจารย์และคณะกรรมการที่ต้องการทดสอบฟังก์ชันสำคัญทั้งหมดของระบบให้ครบถ้วนในเวลาอันสั้น ขอแนะนำขั้นตอนการทดสอบดังต่อไปนี้:

### ⏱️ ขั้นตอนที่ 1: เข้าสู่ระบบด้วยบัญชีทดสอบ (นาทีที่ 1)
1. เปิดหน้าเว็บ `http://localhost:3000/auth`
2. กรอกอีเมล `free-demo@evelyai.local` และรหัสผ่าน `demo1234` แล้วกด **"เข้าสู่ระบบ"**
3. ระบบจะพาไปยังหน้าเริ่มต้นบทสนทนา `/new`

### ⏱️ ขั้นตอนที่ 2: ทดสอบการแชทและการแตะคำศัพท์ (นาทีที่ 2)
1. พิมพ์ข้อความภาษาอังกฤษ เช่น `"Hello, I want to practice English for traveling."` แล้วกดส่ง
2. สังเกตว่า AI ตอบกลับเป็นประโยคภาษาอังกฤษที่เป็นธรรมชาติ พร้อมปิดท้ายด้วยคำถามปลายเปิดเสมอ
3. **แตะคำศัพท์ภาษาอังกฤษคำใดก็ได้ในข้อความของ AI:**
   - การ์ดความหมายจะแสดงขึ้นมาทันที (คำแปลภาษาไทย, คำนิยาม, Part of Speech, ตัวอย่างการใช้)
   - แตะปุ่ม **"บันทึกคำศัพท์"** เพื่อเพิ่มคำนั้นเข้าสู่คลังคำศัพท์ส่วนตัว
4. ทดสอบกดไอคอนลำโพงเพื่อฟังเสียงอ่านภาษาอังกฤษ (TTS)

### ⏱️ ขั้นตอนที่ 3: ทดสอบมินิเกมทบทวนคำศัพท์ SM-2 (นาทีที่ 3)
1. ไปที่เมนูด้านล่างหรือแถบนำทาง เลือกเมนู **"โหมดการเล่น" (`/refresh`)**
2. ท่านจะพบรายการคำศัพท์ 6 คำที่ถึงกำหนดทบทวนวันนี้ (Due for Review)
3. กดปุ่ม **"เริ่มทบทวน"** เพื่อทดสอบมินิเกมทั้ง 3 โหมด:
   - **Matching Game:** จับคู่คำศัพท์ภาษาอังกฤษกับคำแปลภาษาไทย
   - **Typing Game:** พิมพ์สะกดคำศัพท์ภาษาอังกฤษตามคำใบ้
   - **Speak Game:** ฝึกออกเสียงคำศัพท์
4. เมื่อเล่นจบแต่ละข้อ ระบบจะคำนวณคะแนนคุณภาพ (Quality 0–5) และอัปเดตรอบการทบทวนครั้งต่อไปตามสูตร SM-2 อัตโนมัติ

### ⏱️ ขั้นตอนที่ 4: ตรวจสอบคลังคำศัพท์และประวัติการเรียน (นาทีที่ 4)
1. ไปที่เมนู **"คลังคำศัพท์" (`/words`)**
2. สังเกตสถานะสีของคำศัพท์ (คำที่ถึงกำหนดทบทวน, คำที่จำได้แล้ว, คำใหม่)
3. สามารถค้นหาคำศัพท์และจัดเรียงตามวันที่หรือตัวอักษรได้
4. ไปที่เมนู **"ล่าสุด" (`/recents`)** เพื่อดูประวัติบทสนทนาย้อนหลังและกดเปิดอ่านได้

### ⏱️ ขั้นตอนที่ 5: ทดสอบบัญชีพรีเมียมและระบบงบประมาณ (นาทีที่ 5)
1. ออกจากระบบ แล้วเข้าสู่ระบบใหม่ด้วยบัญชี `premium-demo@evelyai.local` (รหัสผ่าน `demo1234`)
2. เริ่มบทสนทนาใหม่ และทดสอบฟีเจอร์พรีเมียม:
   - **Reply Suggestions:** สังเกตตัวเลือกประโยคตอบกลับที่ AI แนะนำด้านล่าง
   - **Grammar Feedback:** พิมพ์ประโยคที่มีไวยากรณ์ผิด เช่น `"She go to school yesterday."` สังเกตว่าระบบตรวจพบและแสดงแถบคำแนะนำแก้ไขไวยากรณ์ที่ถูกต้อง
3. ไปที่หน้า **"โปรไฟล์" (`/profile`)** เพื่อดูเกจวัดงบประมาณรายวัน (Micro-baht µ฿)

## 📱 รายละเอียดฟังก์ชันหลักของระบบ (Feature Breakdown)

### 1. หน้าแชทกับ AI (`/new`, `/chat/[id]`)
- **การสนทนาแบบไดนามิก:** AI ปรับระดับบทสนทนาตามผู้เรียน และจบบทสนทนาด้วยคำถามปลายเปิดเพื่อกระตุ้นให้ผู้เรียนฝึกพูด
- **ระบบถอดความคำศัพท์ (Tokenizer):** แยกประโยคออกเป็นคำๆ ให้ผู้เรียนแตะดูความหมายได้ทุกคำโดยไม่ตัดบริบท
- **ระบบป้อนข้อมูลด้วยเสียง (STT) และฟังเสียงอ่าน (TTS):** กดปุ่มไมโครโฟนเพื่อพูดภาษาอังกฤษ และกดปุ่มลำโพงเพื่อฟังสำเนียงที่ถูกต้อง

### 2. คลังคำศัพท์ส่วนตัว (`/words`)
- รวบรวมคำศัพท์ทั้งหมดที่ผู้เรียนเคยกดบันทึกไว้จากการแชท
- แสดงระดับความชำนาญ (Leitner Box 1 ถึง 5) และวันที่ต้องทบทวนในรอบถัดไป
- มีระบบค้นหาและกรองคำศัพท์อย่างรวดเร็ว

### 3. โหมดทบทวนคำศัพท์ผ่านมินิเกม (`/refresh`)
- ใช้อัลกอริทึม **SuperMemo 2 (SM-2)** วิเคราะห์ความถี่ในการทบทวนคำศัพท์ตามความยากง่าย
- รวม 3 มินิเกมที่ฝึกครบทั้งการจำความหมาย (Matching), การสะกดคำ (Typing), และการออกเสียง (Speak)

### 4. หน้าโปรไฟล์และการตั้งค่างบประมาณ (`/profile`)
- แสดงสถานะบัญชี (Free / Premium)
- แสดงแถบวัดการใช้งบประมาณ Token รายวัน (หน่วยไมโครบาท µ฿)
- สลับโหมดการแสดงผล (Light Mode / Dark Mode)
- **Data Privacy & PDPA:** ปุ่มรีเซ็ตข้อมูลการเรียนรู้ และปุ่มขอลบบัญชีถาวร

## ❓ คำถามที่พบบ่อยและการแก้ไขปัญหา (Troubleshooting & FAQ)

- **Q: ไมโครโฟนในเกม Speak หรือในแชทไม่ทำงาน?**  
  *A:* กรุณาตรวจสอบว่าเบราว์เซอร์ได้รับอนุญาตให้เข้าถึงไมโครโฟน (Microphone Permission) หรือไม่ และแนะนำให้ใช้ Google Chrome หรือ Safari เพื่อรองรับ Web Speech API ได้อย่างสมบูรณ์
- **Q: ขึ้นข้อความเตือนว่าเกินงบประมาณรายวัน (Budget Exhausted)?**  
  *A:* ระบบมีการจำกัดค่าใช้จ่าย Token ต่อวันสำหรับผู้ใช้ Free Tier งบประมาณจะถูกรีเซ็ตอัตโนมัติทุกเที่ยงคืน (เวลาประเทศไทย) หรือสามารถอัปเกรดเป็น Premium เพื่อเพิ่มโควต้าได้
- **Q: ทดสอบการชำระเงิน Stripe ได้อย่างไรโดยไม่ต้องใช้บัตรจริง?**  
  *A:* ระบบรองรับ Stripe Mock Mode เมื่อตั้งค่า `STRIPE_SECRET_KEY=sk_test_mock` ในไฟล์ `.env` ทำให้สามารถทดสอบ Flow การสมัครสมาชิกได้โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ตไปยัง Stripe
